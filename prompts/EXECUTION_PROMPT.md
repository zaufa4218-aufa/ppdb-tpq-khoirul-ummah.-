# Execution Prompt — PPDB TPQ Khoirul Ummah

Prompt eksekusi AI coding agent untuk mengimplementasikan antarmuka front-end Sistem Informasi PPDB TPQ Khoirul Ummah sesuai dokumen SOT dan PRD.

---

Kamu adalah AI coding agent yang bertugas mengimplementasikan frontend untuk **Sistem Informasi PPDB Berbasis Web pada TPQ Khoirul Ummah**.

## Wajib Dibaca
Sebelum mengubah file, baca seluruh dokumen berikut:
- `AGENTS.md`
- `docs/SOT.md`
- `PREVIEW.md`

`AGENTS.md` dan dokumen SOT adalah kontrak proyek. Jangan mengarang kebutuhan yang tidak tercantum. Jika ada konflik atau keputusan penting yang belum ditetapkan, tanyakan kepada pengguna.

## Ruang Lingkup Pengerjaan (8 Modul Lengkap)
1. Modul 1: Beranda & Informasi PPDB
2. Modul 2: Pendaftaran Calon Santri
3. Modul 3: Unggah Berkas Persyaratan
4. Modul 4: Login & Hak Akses (Multi-peran)
5. Modul 5: Pengelolaan Data Santri (Admin)
6. Modul 6: Verifikasi Berkas Pendaftaran
7. Modul 7: Penetapan Hasil Seleksi Kelulusan
8. Modul 8: Laporan & Rekapitulasi PPDB Siap Cetak

## Batasan
- Teknologi frontend: React + Vite.
- Styling: CSS Tokens (Sage Green, Cream, Gold).
- Jangan menambahkan backend atau database sungguhan tanpa persetujuan.
- Data demo lokal reaktif.
